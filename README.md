# Loopsmith

Turn AI-generated spritesheets into smooth, clean animated emojis and GIFs — right in your browser.

**Features:** manual + guided slicing with clean edges · jitter-free auto stabilization · brush, eraser, fill & color picker · any background · Discord-ready GIF export.

**Run locally:** `npm install` then `npm run dev`, and open http://localhost:3000
